# 架構設計與防 Leakage 說明

## 整體架構

```
collectors  →  cleaners  →  features  →  models  →  execution
     ↓             ↓            ↓           ↓           ↓
   原始資料      清洗後資料    特徵矩陣    預測/信號    下單執行
```

## 防 Data Leakage 機制

1. **時間切分嚴格遵守**：訓練集只使用過去資料，驗證/測試集使用未來資料。
2. **特徵計算禁止前瞻**：所有技術指標、統計量僅使用當下及過去的 bar。
3. **交叉驗證使用 Purged / Embargo**：避免相鄰樣本資訊洩漏。
4. **Label 生成與特徵分離**：標籤產生流程獨立，並在時間軸上正確對齊。

詳細實作請參考 `src/` 各模組原始碼。
